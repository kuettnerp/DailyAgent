# DailyAgent — daily-assistant plugin

A Claude Code plugin that acts as a personal daily-planning assistant: you
talk to it, it remembers things across days, learns how long your tasks
actually take, learns new routines when you explicitly ask it to, does web
research, and nudges you to keep your real calendar/reminders in sync
(without ever touching them itself).

## What it does

| Skill | Triggers on | What it does |
|---|---|---|
| `daily-planning` | "what's on my plate today", "let's plan the day", end-of-day wrap-up | Loads yesterday's unfinished tasks, asks what's new, gets a time estimate for each (using history when available), helps prioritize, and walks through a calendar-confirmation step for anything appointment-like. |
| `task-timer` | "start timing this", "stop the timer", "I just finished X" | Stopwatch-style start/stop (or manual after-the-fact logging) that feeds real durations back into estimate history. |
| `research-assistant` | "look into X for me", "research Y" | Web research via search + fetch, reported as bottom line → sourced findings → links → a clearly-labeled personal take. |
| `skill-learning` | "learn how to do this", "just handle this for me from now on" | Always asks before learning anything. On yes, saves a step-by-step playbook that's usable immediately and also generates a real, independently-triggering skill under `skills/learned/`. |
| `skills/learned/*` | whatever you taught it | Generated by the above — read/edit/delete freely. |

A `SessionStart` hook quietly checks for carried-over tasks from the last
active day and surfaces them as context, so the assistant can offer a
check-in without you having to remember to ask.

## Memory & privacy

All state is stored **locally, outside this git repo**, under
`~/.daily-assistant/` (override with the `DAILY_ASSISTANT_HOME` env var):

- `days/YYYY-MM-DD.json` — each day's tasks, estimates, actuals, priorities, calendar-confirmation flags
- `task_history.json` — estimate vs. actual history per task, used to auto-suggest future estimates
- `timer_state.json` — the currently running timer, if any
- `learned_playbooks.json` — registry of things you've asked it to learn

Nothing here is committed, pushed, or synced by this repo. It's plain JSON
you can open, edit, or delete by hand at any time.

## Calendar & Reminders — status

**Not automated, by design (for now).** The assistant will always just
*ask* you to confirm something's on your calendar/reminders and propose
exact wording/timing for you to double-check first. Two integrations were
investigated but deliberately left unwired (no credentials touched this
session):

- [`docs/integrations/apple-calendar-caldav.md`](docs/integrations/apple-calendar-caldav.md) — iCloud Calendar + Reminders over CalDAV (Apple's own sync protocol), with a ready-to-run reference script that only activates with an app-specific password you set as a local env var on your own machine.
- [`docs/integrations/skylight.md`](docs/integrations/skylight.md) — the Skylight smart-display calendar: an official-but-gated API path vs. an existing unofficial/community one, with tradeoffs.

## Installing

**Quick local testing** (no marketplace step, loads straight from this checkout):

```
claude --plugin-dir /path/to/DailyAgent
```

**Persistent local install**, from within a Claude Code session:

```
/plugin marketplace add /path/to/DailyAgent
/plugin install daily-assistant@dailyagent
```

Both skills and hooks are picked up without a full restart — run
`/reload-plugins` after installing/updating if a session was already open.

## Repo layout

```
.claude-plugin/       plugin.json + marketplace.json (this repo doubles as its own marketplace)
skills/                one directory per skill, each with a SKILL.md
  daily-planning/
  task-timer/
  research-assistant/
  skill-learning/
  learned/             generated skills land here
scripts/               shared Python CLIs the skills shell out to (lib.py, plan_cli.py, timer_cli.py, playbook_cli.py)
hooks/                 SessionStart hook (surfaces carried-over tasks)
docs/integrations/     calendar/reminders investigation, intentionally unwired
```

## Trying the CLIs directly

Every skill just shells out to a small, dependency-free Python CLI — you
can run these yourself to see the data model:

```
python3 scripts/plan_cli.py show
python3 scripts/plan_cli.py add-task --title "Write proposal" --estimate 45
python3 scripts/timer_cli.py start --task "Write proposal"
python3 scripts/timer_cli.py stop --mark-done
python3 scripts/plan_cli.py suggest-estimate --title "Write proposal"
python3 scripts/playbook_cli.py list
```
