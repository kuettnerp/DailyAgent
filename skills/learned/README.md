# Learned skills

This directory is intentionally empty at first. When you ask the assistant
to learn a new routine (see `skills/skill-learning/SKILL.md`), it writes a
new `learned-<slug>/SKILL.md` in here via `scripts/playbook_cli.py add`.
Each one becomes an independent, auto-triggering Claude Code skill the next
time the plugin reloads.

Feel free to read, edit, or delete anything generated here -- these are
plain files, not a special format.
